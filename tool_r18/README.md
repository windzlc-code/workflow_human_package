# InFinio

InFinio 是一个一站式智能体自动化平台，面向内容创作、模型调用、工作流组织和发布执行。界面强调直接进入工作，不做花哨首页，用户打开后就能立刻开始新项目、继续历史会话，或者切入具体任务流。

## 核心功能

### 1. 会话式任务启动
- 从首页直接输入目标，与 Agent 连续对话推进任务
- 支持从开始页快速发起原创剧本、参考改编、视频工作流等任务
- 把“新建项目、继续会话、切换任务”放在同一个工作入口里

### 2. 模型分层选择
- 文本模型支持供应商与具体模型两级选择
- 当前已支持 `Google Gemini` 与 `OpenAI GPT`
- GPT 侧补充了 `GPT 5.5`、`GPT 5.4`
- 图像模型支持独立选择与分辨率切换

### 3. 内容创作工作流
- 人设创建
- 文案撰写
- 导出与发布
- 人设档案独立保存，支持后续复用、切换和连续积累推文内容

### 4. 发布与自动化执行
- 支持云机发布工作流
- 支持图文内容管理、发布前编辑、批量选择数量
- 支持围绕不同平台定制验证和自动化执行逻辑

### 5. 历史与项目延续
- 左侧保留对话历史和快捷任务
- 支持从已有工作继续推进，而不是每次重新开始
- 产品定位更偏“持续工作台”，不是一次性生成器

## 典型使用流程

1. 从首页点击“开始新项目”或直接输入目标
2. 选择任务类型，例如原创剧本、参考改编、视频工作流
3. 选择文本模型供应商，再选择具体模型
4. 进入创作流程，生成人设、文案和素材
5. 在导出或发布前检查内容并做最后编辑
6. 通过历史会话或存档持续迭代

## 产品价值

InFinio 的核心不是把某一个 AI 能力单点做强，而是把“任务开始、模型选择、内容生成、历史延续、发布执行”收进一套连续工作界面里。用户不需要在多个工具之间来回切，直接在一个界面里完成整个链路。

这件事最重要的不是多一个按钮，而是减少上下文切换。用户的感觉应该是：打开就能做，做到一半还能继续，换模型也不需要重新学界面。
